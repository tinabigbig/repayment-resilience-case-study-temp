# Results on simulated data

- 6,000 simulated accounts, of which 3,408 were eligible and randomly assigned.
- On-time next payment: 80.6% for aligned due dates vs 72.0% for control.
- Difference: 8.62 percentage points (95% CI 5.78 to 11.47).
- I built a 7.5-point lift into the simulation, so this shows the analysis works. It says nothing about real borrowers.
- Sample size needed (72% baseline, 5% significance, 80% power): 7,733 per group for a 2-point lift, 3,395 for 3 points, 1,191 for 5 points. This demo is too small to detect 3 points.
- 179 accounts would go to a person for a hardship affordability review.
- No charge-off or recovery data exists here, so I don't estimate savings.
